# ESP32-Lora-Agri-Multinode

(English)
A complete, self-sustaining IoT solution for remote farm monitoring. Deployed sensor nodes collect soil and environmental data and transmit it over long distances via LoRa to a Wi-Fi gateway, which forwards it to the cloud. Built with ESP32/ESP8266, SX1278, and solar power.
(Indonesia)
Sistem monitoring pertanian presisi multi-node bertenaga surya. Node sensor mengirim data tanah dan lingkungan via LoRa ke gateway, lalu diteruskan ke cloud untuk visualisasi real-time. Dibangun dengan ESP32 dan modul SX1278
